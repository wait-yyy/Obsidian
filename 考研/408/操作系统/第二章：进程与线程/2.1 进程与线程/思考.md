### 核心脉络

```
程序（静态）
  ↓  加载到内存
进程（动态）= PCB + 程序段 + 数据段
  │
  ├── 状态转换
  │   创建 → 就绪 → 运行 → 终止
  │              ↑     ↓
  │              └── 阻塞
  │
  ├── 进程控制（原语）
  │   创建 / 撤销 / 阻塞 / 唤醒 / 切换
  │
  ├── 进程通信（IPC）
  │   共享存储 / 消息传递 / 管道通信
  │
  └── 线程（轻量级进程）
      用户级 vs 内核级
      一对一 / 多对一 / 多对多
```

### 易混点对比

| 对比项 | 说明 |
|--------|------|
| 程序 vs 进程 | 静态 vs 动态 |
| 并发 vs 并行 | 宏观同时vs同一时刻 |
| 进程 vs 线程 | 资源分配单位 vs 调度单位 |
| 阻塞 vs 挂起 | 阻塞在内存，挂起在外存 |
