## 进程与线程 — 思维导图

### 🌳 进程的定义

- **进程** = `PCB` + `程序段` + `数据集`
  - **PCB** — 进程唯一标识，OS 通过 PCB 感知进程
  - **程序段** — 静态代码
  - **数据集** — 运行时数据
- **程序** ≠ **进程**
  - 程序：静态，存在磁盘
  - 进程：动态，占用 CPU/内存
  - 一个程序 → 多个进程（如打开多个浏览器）
  - 一个进程 → 涉及多个程序（调用关系）
- **进程控制块 (PCB)**
  - 进程存在的唯一标志
  - 保存：状态 / 优先级 / 寄存器 / 内存指针 ...

---

### 🌳 进程的特征

- **动态性** ←→ 程序静态
- **并发性** ← 调度策略决定执行速度
- **异步性** → **不可再现性**
  - 执行顺序不确定 → 结果不稳定
  - ⚡ 需要 → [[同步与互斥]]（信号量、管程）

🤔 *为什么不可再现？* 并发环境下，`进程A` 和 `进程B` 谁先执行取决于调度器，共享资源访问顺序不同 → 结果不同。

---

### 🌳 进程调度

- **调度决定**：哪个进程运行、运行多久
- **影响**：并发进程的**相对速度**
- **调度算法举例**
  - 先来先服务 (FCFS)
  - 时间片轮转 (RR)
  - 优先级调度
  - 多级反馈队列
- ⚡ → [[2.2 处理机调度]]

### 🧠 脉络总结

```
程序（静态）
  └── 加载到内存 → 进程（动态）
        ├── 由 PCB 管理
        ├── 多个进程并发执行
        │     └── 调度策略决定执行顺序
        │           └── 不可再现性 ✦←── 同步机制解决
        └── 进程切换 → 上下文切换（保存/恢复 PCB）
```
