## 2.1 进程与线程 — 思维导图

### 一、进程的概念

#### 进程 vs 程序
- **程序**：静态的，存放在磁盘的可执行文件
- **进程**：动态的，程序的一次执行过程
- 同一个程序多次执行 → 对应多个进程

#### 进程的组成（进程映像）
```
进程 = PCB + 程序段 + 数据段
 ├── PCB（进程控制块）：给OS用，进程唯一标识
 ├── 程序段：给进程自己用，代码（指令序列）
 └── 数据段：给进程自己用，运行中的变量数据
```

#### PCB 核心内容
- 进程描述信息：PID、UID
- 进程控制和管理信息：状态、优先级
- 资源分配清单：文件、内存、I/O设备
- 处理机相关信息：PSW、PC、寄存器

#### 进程的特征
| 特征 | 说明 |
|------|------|
| **动态性** | 最基本特征，进程动态产生、变化、消亡 |
| **并发性** | 多个进程可并发执行 |
| **独立性** | 独立运行、独立获得资源、独立接受调度 |
| **异步性** | 不可预知速度推进 → 需要同步机制 |
| **结构性** | 每个进程配一个PCB |

### 二、进程的状态与转换

#### 五种状态

```
创建态 → 就绪态 → 运行态 → 终止态
              ↑       ↓
              └── 阻塞态
```

| 状态 | 说明 |
|------|------|
| **创建态（New）** | 分配资源、初始化PCB |
| **就绪态（Ready）** | 万事俱备，只欠CPU |
| **运行态（Running）** | 占有CPU并运行 |
| **阻塞态（Blocked）** | 等待事件（缺资源） |
| **终止态（Terminated）** | 回收资源、撤销PCB |

#### 状态转换核心

| 转换 | 触发 |
|------|------|
| 创建态 → 就绪态 | 系统完成创建 |
| 就绪态 → 运行态 | **被调度**（获得CPU）|
| 运行态 → 就绪态 | 时间片到 / 被抢占 |
| 运行态 → 阻塞态 | 等待资源 / 事件（**主动**）|
| 阻塞态 → 就绪态 | 资源到位 / 事件发生（**被动**）|
| 运行态 → 终止态 | 运行结束 / 错误 |

> 💡 不能：阻塞态 → 直接 → 运行态；就绪态 → 直接 → 阻塞态

#### 进程的组织方式
- **链接方式**：按状态分队列（就绪队列、阻塞队列）
- **索引方式**：建索引表

### 三、进程控制

#### 原语（原子操作）
- 通过 **关中断 / 开中断** 实现原子性
- 一气呵成，不可中断

#### 核心原语
| 原语 | 过程 |
|------|------|
| **创建原语** | 申请PCB → 分配资源 → 初始化PCB → 插入就绪队列 |
| **撤销原语** | 找PCB → 剥夺CPU → 终止子进程 → 回收资源 → 删PCB |
| **阻塞原语** | 保护现场 → 设阻塞态 → 插入等待队列 |
| **唤醒原语** | 找PCB → 移出等待队列 → 设就绪态 → 插入就绪队列 |
| **切换原语** | 保存环境 → 移入相应队列 → 选新进程 → 恢复环境 |

> ⚠️ 阻塞原语和唤醒原语**必须成对使用**

### 四、进程通信（IPC）

| 方式 | 特点 |
|------|------|
| **共享存储** | 基于数据结构（低级）或基于存储区（高级）|
| **消息传递** | 直接通信（挂到PCB消息队列）或间接通信（信箱）|
| **管道通信** | 半双工，互斥访问，FIFO，没写满不能读 |

### 五、线程

#### 概念
- **线程** = 轻量级进程，CPU执行的最小单位
- **引入线程后**：
  - 进程：资源分配的基本单位
  - 线程：调度的基本单位

#### 线程的实现方式

| 类型 | 管理方 | 切换开销 | 特点 |
|------|--------|---------|------|
| **用户级线程** | 线程库（应用）| 小（用户态）| OS意识不到，一个阻塞全阻塞 |
| **内核级线程** | 操作系统内核 | 大（核心态）| 可多核并行，一个阻塞不影响其他 |

#### 多线程模型

| 模型 | 映射 | 特点 |
|------|------|------|
| **一对一** | 1用户级 → 1内核级 | 并发度高，开销大 |
| **多对一** | n用户级 → 1内核级 | 效率高，但一个阻塞全阻塞 |
| **多对多** | n用户级 → m内核级 | 兼顾并发度和开销 |
