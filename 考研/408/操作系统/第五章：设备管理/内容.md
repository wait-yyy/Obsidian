## 第五章：设备管理 — 思维导图

### 一、I/O 控制方式

```
程序直接控制 ──→ 中断驱动 ──→ DMA ──→ 通道控制
  （轮询）      （中断通知）   （块传输）  （通道程序）
  CPU忙等       每字中断      块级传输    一组块传输
  效率极低       效率提升       效率高      效率最高
```

#### 四种方式对比
| 方式 | 数据流向 | 单位 | 特点 |
|------|---------|------|------|
| **程序直接控制** | 设备→CPU→内存 | 字 | CPU忙等，利用率极低 |
| **中断驱动** | 设备→CPU→内存 | 字 | 每字中断，频繁消耗CPU |
| **DMA** | 设备↔内存（直接）| 连续块 | CPU只在开始结束介入 |
| **通道控制** | 设备↔内存 | 一组块 | CPU、通道、设备三者并行 |

### 二、SPOOLing 技术（假脱机）

#### 核心思想
- 用**软件模拟脱机技术**
- 把独占设备改造成**共享设备**（虚拟设备）

#### 组件
```
输入设备 → 输入缓冲区 → 输入井（磁盘）
                             ↓
用户进程 ←─────────────── 输入进程
用户进程 ───────────────→ 输出进程
                             ↓
输出设备 ← 输出缓冲区 ← 输出井（磁盘）
```

| 组件 | 作用 |
|------|------|
| **输入井/输出井** | 磁盘上的区域，收容数据 |
| **输入/输出进程** | 负责数据传输 |
| **输入/输出缓冲区** | 内存中转站 |

#### 共享打印机实例
- 独占打印机 → SPOOLing → 共享（虚拟设备）
- 多个进程申请 → 假脱机进程为每个建请求表 → 挂到队列
- 打印机空闲 → 输出进程取请求 → 打印

### 三、设备分配

#### 分配数据结构（四级表）
```
SDT (系统设备表) → DCT (设备控制表) → COCT (控制器控制表) → CHCT (通道控制表)
```

#### 分配步骤
1. 查 SDT → 找 DCT
2. 设备空闲？→ 分配 → 查 COCT
3. 控制器空闲？→ 分配 → 查 CHCT
4. 通道空闲？→ 分配成功，启动 I/O

- **逻辑设备名（LUT）**：用户编程用逻辑名，系统自动分配物理设备

---

### 四、缓冲区管理

#### 作用
- 缓和 CPU 与 I/O 速度不匹配
- 减少中断频率
- 提高 CPU 与 I/O 并行性

#### 缓冲策略
| 类型 | 说明 | 处理一块数据耗时 |
|------|------|----------------|
| **单缓冲** | 一个缓冲区 | Max(C, T) + M |
| **双缓冲** | 两个缓冲区 | Max(T, C+M) |
| **循环缓冲** | 多个缓冲区循环（in/out指针）| — |
| **缓冲池** | 系统共用（空/输入/输出队列）| — |

> T=数据到缓冲区时间，C=CPU处理时间，M=缓冲区到工作区时间
