## 第四章：文件管理 — 思维导图

### 一、文件系统基础

#### 文件属性
- 文件名、标识符、类型、位置、大小
- 创建/修改时间、所有者、保护信息

#### 文件的逻辑结构
| 类型 | 说明 |
|------|------|
| **无结构文件（流式文件）** | 二进制/字符流，如 .txt |
| **有结构文件（记录式文件）** | 由记录组成 |
| └─ 顺序文件 | 记录顺序排列 |
| └─ 索引文件 | 建索引表实现快速查找 |
| └─ 索引顺序文件 | 分组+索引，可多级索引 |

#### 文件目录
- **FCB（文件控制块）** = 目录项
- **目录结构演进**：
  ```
  单级 → 两级(MFD+UFD) → 树形(路径) → 无环图(共享)
  ```
- **inode（索引结点）**：文件名与信息分离 → 缩小目录项

#### 文件的物理结构（分配方式）
| 方式 | 特点 |
|------|------|
| **连续分配** | 支持随机访问，有碎片，不方便扩展 |
| **隐式链接** | 盘块存指针，只支持顺序访问 |
| **显式链接（FAT）** | FAT常驻内存，支持随机访问 |
| **索引分配** | 每文件一张索引表（多层/混合索引）|

#### 存储空间管理
| 方法 | 说明 |
|------|------|
| **空闲表法** | 记录连续空闲区 |
| **空闲链表法** | 空闲盘块链 / 空闲盘区链 |
| **位示图法** | 二进制位表示盘块状态 |
| **成组链接法** | UNIX使用，超级块管理分组 |

#### 文件操作
- 创建 / 删除 / 打开 / 关闭 / 读 / 写
- **打开文件表**：系统级 + 进程级

#### 文件共享
| 方式 | 说明 |
|------|------|
| **硬链接** | 目录项指向同一 inode，count计数 |
| **软链接** | 创建 Link 文件记录路径（类似快捷方式）|

#### 文件保护
- 口令保护 / 加密保护 / 访问控制（ACL）

### 二、文件系统

#### 层次结构
```
用户接口 → 文件目录系统 → 存取控制 → 逻辑文件系统 → 物理文件系统 → 设备管理 → 辅助分配
```

#### 外存布局
```
MBR → 分区表 → 引导块 → 超级块 → inode区 → 根目录 → 文件区
```

#### 虚拟文件系统（VFS）
- 向上提供统一系统调用接口
- 每打开一个文件 → 内存中创建 **vnode**
