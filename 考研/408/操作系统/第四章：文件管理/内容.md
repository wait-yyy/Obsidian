## 第四章：文件管理 — 思维导图

### 一、文件系统基础

#### 文件属性
- 文件名、标识符、类型、位置、大小
- 创建/修改时间、所有者、保护信息

#### 文件的逻辑结构
| 类型 | 说明 |
|------|------|
| **无结构文件（流式文件）** | 二进制/字符流，如 .txt |
| **有结构文件（记录式文件）** | 由记录组成 |
| └─ 顺序文件 | 记录顺序排列 |
| └─ 索引文件 | 建索引表实现快速查找 |
| └─ 索引顺序文件 | 分组+索引，可多级索引 |

#### 文件目录
- **FCB（文件控制块）** = 目录项
- **目录结构演进**：
  ```
  单级 → 两级(MFD+UFD) → 树形(路径) → 无环图(共享)
  ```
- **inode（索引结点）**：文件名与信息分离 → 缩小目录项

#### 文件的物理结构（分配方式）
| 方式 | 特点 |
|------|------|
| **连续分配** | 支持随机访问，有碎片，不方便扩展 |
| **隐式链接** | 盘块存指针，只支持顺序访问 |
| **显式链接（FAT）** | FAT常驻内存，支持随机访问 |
| **索引分配** | 每文件一张索引表（多层/混合索引）|

#### 存储空间管理
| 方法 | 说明 |
|------|------|
| **空闲表法** | 记录连续空闲区 |
| **空闲链表法** | 空闲盘块链 / 空闲盘区链 |
| **位示图法** | 二进制位表示盘块状态 |
| **成组链接法** | UNIX使用，超级块管理分组 |

#### 文件操作
- 创建 / 删除 / 打开 / 关闭 / 读 / 写
- **打开文件表**：系统级 + 进程级

#### 文件共享
| 方式 | 说明 |
|------|------|
| **硬链接** | 目录项指向同一 inode，count计数 |
| **软链接** | 创建 Link 文件记录路径（类似快捷方式）|

#### 文件保护
- 口令保护 / 加密保护 / 访问控制（ACL）

### 二、文件系统

#### 层次结构（从上到下）
```
用户接口（处理系统调用 Read/Write/Open/Close）
    ↓
文件目录系统（按路径找FCB/inode，管理目录）
    ↓
存取控制模块（验证用户访问权限）
    ↓
逻辑文件系统与文件信息缓冲区（记录号→逻辑地址）
    ↓
物理文件系统（逻辑地址→物理地址）
    ↓
辅助分配模块（分配/回收存储空间）
    ↓
设备管理模块（分配设备、缓冲区、磁盘调度、启动设备）
    ↓
设备
```

#### 外存布局
```
原始磁盘 → 物理格式化（划分扇区、检测坏扇区）
  → 磁盘分区（分卷 Volume）
  → 逻辑格式化（文件系统初始化）
```

**逻辑格式化后的结构**：
```
| MBR | 引导块 | 超级块 | inode区 | 根目录 | 文件区 |
```
- **MBR（主引导记录）**：包含磁盘引导程序和分区表
- **超级块**：文件系统元信息（空闲块数、inode数等）
- **inode 区**：存储所有文件的索引结点

#### 文件系统在内存中的结构
- **安装表** — 记录已挂载的文件系统
- **目录缓存** — 近期访问过的目录文件缓存在内存
- **系统打开文件表** — 每个打开文件一个表项（含打开计数器）
- **进程打开文件表** — 每个进程一张，指向系统打开文件表

#### Open 系统调用的过程
1. 用户进程调用 open → 系统调用 → VFS
2. 根据文件路径逐层查找目录 → 找到 FCB/inode
3. 检查权限
4. 在系统打开文件表中分配表项（若已打开则计数器+1）
5. 在进程打开文件表中增加表项，指向系统打开文件表
6. 返回文件描述符 fd

#### 虚拟文件系统（VFS）
- **向上**：提供统一标准的系统调用接口，屏蔽底层差异
- **向下**：要求下层文件系统必须实现规定的函数（open/read/write）
- 每打开一个文件 → 在内存中创建 **vnode**（统一的数据结构）
- 不同文件系统的 vnode 指向各自的具体文件结构
