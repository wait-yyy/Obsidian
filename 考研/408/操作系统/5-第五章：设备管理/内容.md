## 第五章：设备管理 — 思维导图

> 基于王道课件补充：I/O 硬件、DMA 控制器、设备分配、缓冲区计算

### 一、I/O 硬件

#### I/O 设备组成
- **机械部件** — 设备本身
- **电子部件** — **设备控制器**（适配器）

#### 设备控制器功能
- 接收和识别 CPU 命令（控制寄存器）
- 数据交换（数据寄存器）
- 标识和报告设备状态（状态寄存器）
- 地址识别
- 数据缓冲

#### 内存映像 I/O vs 寄存器独立编址
| 方式 | 特点 |
|------|------|
| **内存映像 I/O** | 寄存器与内存统一编址，可用内存操作指令控制，指令更简化 |
| **寄存器独立编址** | 寄存器单独地址，需专门 I/O 指令，需指明寄存器地址和控制器编号 |

---

### 二、I/O 控制方式

```
程序直接控制 ──→ 中断驱动 ──→ DMA ──→ 通道控制
  （轮询）       （中断通知）   （块传输）  （通道程序）
```

| 方式 | CPU干预频率 | 数据单位 | 数据流向 | 特点 |
|------|-----------|---------|---------|------|
| **程序直接控制** | 频繁轮询 | 字 | 设备→CPU→内存 | 实现简单，CPU忙等 |
| **中断驱动** | 每字中断 | 字 | 设备→CPU→内存 | CPU可并行，但每字中断 |
| **DMA** | 开始+结束时 | 块 | 设备↔内存（直接）| 效率高 |
| **通道控制** | 极低 | 一组块 | 设备↔内存 | 三者并行，最复杂 |

#### DMA 控制器结构
- **DR（数据寄存器）**：暂存数据
- **MAR（内存地址寄存器）**：数据在内存中的位置
- **DC（数据计数器）**：剩余读/写字节数
- **CR（命令/状态寄存器）**：I/O 命令或设备状态

---

### 三、I/O 软件层次结构

```
用户层软件          ← 假脱机技术（SPOOLing）
设备独立性软件      ← I/O调度、设备保护、设备分配、缓冲区管理
设备驱动程序        ← 与硬件相关，每类设备一个驱动
中断处理程序        ← 处理中断信号
硬件                ← 设备
```

#### 各层功能
- **用户层软件**：实现 SPOOLing 技术，请求磁盘设备的服务
- **设备独立性软件**：I/O 调度、设备保护、设备分配与回收、缓冲区管理
- **设备驱动程序**：每类设备对应一个驱动，负责与硬件交互
- **中断处理程序**：处理设备中断信号

---

### 四、SPOOLing 技术（假脱机）

```
输入设备 → 输入缓冲区 → 输入进程 → 输入井（磁盘）
                                        ↓
                                    用户进程
                                        ↓
输出设备 ← 输出缓冲区 ← 输出进程 ← 输出井（磁盘）
```

#### 共享打印机实例
- 独占打印机 → SPOOLing → **共享设备**（虚拟设备）
- 多进程申请 → 假脱机进程为每个建**打印请求表** → 挂到文件队列
- 打印机空闲 → 输出进程取请求 → 从输出井取数据 → 打印

### 五、设备分配

#### 四级数据结构
```
系统设备表(SDT) → 设备控制表(DCT) → 控制器控制表(COCT) → 通道控制表(CHCT)
```

#### 分配步骤
1. 查 **SDT** → 找 **DCT**（设备类型、标识符、驱动入口）
2. 设备空闲？→ 分配 → 查 **COCT**
3. 控制器空闲？→ 分配 → 查 **CHCT**
4. 通道空闲？→ 分配成功，启动 I/O

**只有设备、控制器、通道三者都分配成功，才算分配成功**

#### 分配改进 — LUT（逻辑设备表）
- **问题**：用户编程用物理设备名 → 不透明、不灵活
- **改进**：用户用**逻辑设备名**编程
- OS 通过 **LUT** 建立逻辑名 ↔ 物理名映射
- LUT 设置：单用户→系统一张；多用户→每用户一张

### 六、缓冲区管理

#### 缓冲区作用
- 缓和 CPU 与 I/O 速度不匹配
- 减少中断频率
- 解决数据粒度不匹配
- 提高 CPU 与 I/O 并行性

#### 缓冲策略（T=输入时间，C=处理时间，M=传送时间）

| 类型 | 说明 | 处理一块数据耗时 |
|------|------|----------------|
| **单缓冲** | 一个缓冲区 | **Max(C, T) + M** |
| **双缓冲** | 两个缓冲区 | **Max(T, C+M)** |
| **循环缓冲** | 多个缓冲区循环队列（in/out指针）| — |
| **缓冲池** | 系统共用（空/输入/输出队列 + hin/sin/hout/sout）| — |

> 口诀：单缓冲 = 大者 + M；双缓冲 = 取大者

---

### 七、磁盘调度 ★

#### 磁盘结构
- 柱面（Cylinder）、磁头（Head）、扇区（Sector）
- 寻道时间 + 旋转延迟 + 传输时间

#### 磁盘调度算法

| 算法 | 核心 | 特点 |
|------|------|------|
| **FCFS** | 按请求顺序调度 | 公平，但性能差 |
| **SSTF（最短寻道优先）** | 优先处理最近的请求 | 性能好，但可能饥饿 |
| **SCAN（电梯算法）** | 单向移动，到头折返 | 解决了饥饿 |
| **C-SCAN** | 单向移动，直接回起点 | 各位置等待时间更均匀 |
| **LOOK** | SCAN 改进，无请求即可折返 | 效率更高 |
| **C-LOOK** | C-SCAN 改进 | 综合最优 |

#### 减少延迟时间的方法
- 扇区交替编号（逻辑相邻扇区物理上隔开）
- 柱面扇区错位（不同盘面错开扇区起始）
