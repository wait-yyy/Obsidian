# 题解思路

## 1. 核心思路

由于：

```text
n * m <= 16
```

总格子数很小，可以把整个矩阵看作一个状态，然后进行状态搜索。

对于当前状态：

1. 枚举当前矩阵中的所有合法路径；
2. 对每一条合法路径模拟一次操作；
3. 得到新的矩阵状态；
4. 递归搜索新状态。

为了避免重复计算同一个局面，使用记忆化搜索。

---

## 2. 状态定义

设：

```cpp
solve(state)
```

表示从当前矩阵状态 `state` 出发，未来能够选择出的最长路径长度。

最终答案就是：

```cpp
solve(初始状态)
```

---

## 3. 状态转移

对于当前状态，枚举所有合法路径 `path`。

设路径长度为 `len`，操作后得到新状态 `nextState`。

那么：

```cpp
solve(state) = max(solve(state), len);
solve(state) = max(solve(state), solve(nextState));
```

也就是说：

```text
当前状态答案 = 当前能直接选择的最长路径长度
             和
             所有后继状态答案
             的最大值
```

---

## 4. 状态编码

每个格子可能有 `5` 种状态：

```text
0, 1, 2, 3, 4
```

其中：

- `0` 表示空格；
- `1~4` 表示正常数字。

因为最多有 `16` 个格子，所以可以使用五进制压缩整个矩阵。

设：

```text
N = n * m
```

按照从左到右、从上到下的顺序编号，则状态编码为：

```cpp
code = a[0] * 5^0 + a[1] * 5^1 + ... + a[N-1] * 5^(N-1)
```

由于：

```text
5^16 = 152587890625
```

可以放入 `unsigned long long`。

---

## 5. 枚举路径

从每一个非空格子出发 DFS。

DFS 过程中要求：

1. 不能走出矩阵；
2. 不能走到空格；
3. 不能走到已经经过的格子；
4. 只能走到和起点数字相同的格子。

当当前路径长度 `>= 3` 时，这条路径就是一次合法操作。

注意，路径是有方向的。

例如：

```text
A -> B -> C
```

和：

```text
C -> B -> A
```

虽然经过的格子集合一样，但最后一步方向可能不同，所以合并后生成的新数字可能不同，必须分别考虑。

---

## 6. 模拟一次操作

对于路径：

```text
p1 -> p2 -> ... -> pk
```

执行过程为：

1. 复制当前矩阵；
2. 清空路径上的所有格子；
3. 根据 `p(k-1) -> pk` 的方向计算新数字；
4. 在终点 `pk` 放入新数字；
5. 每一行向左坍缩；
6. 每一列向下坍缩；
7. 编码得到新状态。

---

## 7. 坍缩规则

### 每行向左坍缩

对每一行，从左到右收集非空数字，再从左到右放回去。

例如：

```text
1 . 3 . 2
```

向左坍缩后变成：

```text
1 3 2 . .
```

### 每列向下坍缩

对每一列，从下到上收集非空数字，再从下到上放回去。

例如：

```text
1
.
3
.
2
```

向下坍缩后变成：

```text
.
.
1
3
2
```

---

## 8. 搜索为什么会结束？

一次合法操作的路径长度至少为 `3`。

如果路径长度为 `k`，那么操作后：

- 删除前 `k-1` 个格子；
- 保留终点一个格子。

所以非空格子数量减少：

```text
k - 1 >= 2
```

矩阵中最多只有 `16` 个格子，因此操作次数有限，搜索一定会结束。

---

## 9. 正确性证明

### 引理 1：算法枚举到了当前状态下所有合法路径

算法从每一个非空格子出发进行 DFS。

DFS 过程中只会走到上下左右相邻、数字相同、未经过的格子。

这正好满足合法路径的要求。

任意一条合法路径都有一个起点，算法一定会从这个起点开始，并按照路径顺序枚举到它。

因此，算法不会漏掉任何合法路径。

### 引理 2：算法对每条合法路径得到的后继状态正确

对于一条合法路径，算法按照题目规则：

1. 删除路径上的前 `k-1` 个格子；
2. 在终点生成由最后一步方向决定的新数字；
3. 每一行向左坍缩；
4. 每一列向下坍缩。

这与题目规定完全一致。

因此算法得到的后继状态正确。

### 引理 3：`solve(state)` 不小于从该状态出发的最优答案

设最优方案第一步选择路径 `path`，之后进入状态 `nextState`。

根据引理 1，算法一定会枚举到 `path`。

根据引理 2，算法得到的后继状态正是 `nextState`。

算法会取：

```cpp
max(path 的长度, solve(nextState))
```

所以算法不会错过最优方案。

因此 `solve(state)` 不小于最优答案。

### 引理 4：`solve(state)` 不大于从该状态出发的最优答案

算法只会枚举真实合法路径，并且每次转移都严格按照题目规则模拟。

因此算法产生的任意操作序列都是真实可行的。

所以 `solve(state)` 不可能超过最优答案。

### 定理：算法正确

由引理 3 可知，算法答案不小于最优答案。

由引理 4 可知，算法答案不大于最优答案。

因此算法答案等于最优答案，算法正确。

---

## 10. 复杂度分析

设：

```text
N = n * m
```

设从初始状态出发实际能够到达的不同状态数为 `S`。

对于每个状态，需要枚举所有同色简单路径。

网格图中每个点最多有 `4` 个相邻点，简单路径数量可以粗略估计为：

```text
O(N * 3^N)
```

每条路径模拟一次操作需要：

```text
O(N)
```

因此总时间复杂度为：

```text
O(S * N^2 * 3^N)
```

空间复杂度为：

```text
O(S)
```

由于：

```text
N <= 16
```

并且每次操作至少减少 `2` 个非空格子，所以可以接受。



```cpp
#include <bits/stdc++.h>
using namespace std;

using ull = unsigned long long;

int n, m, N;
ull pw5[20];

vector<vector<int>> adj;
unordered_map<ull, int> memo;

int getId(int x, int y) {
    return x * m + y;
}

pair<int, int> getPos(int id) {
    return {id / m, id % m};
}

vector<int> decode(ull code) {
    vector<int> a(N);
    for (int i = 0; i < N; i++) {
        a[i] = code % 5;
        code /= 5;
    }
    return a;
}

ull encode(const vector<int>& a) {
    ull code = 0;
    for (int i = 0; i < N; i++) {
        code += (ull)a[i] * pw5[i];
    }
    return code;
}

int getNewValue(int pre, int ed) {
    auto [x1, y1] = getPos(pre);
    auto [x2, y2] = getPos(ed);

    int dx = x2 - x1;
    int dy = y2 - y1;

    if (dx == 0 && dy == -1) return 1; // 向左
    if (dx == -1 && dy == 0) return 2; // 向上
    if (dx == 0 && dy == 1) return 3;  // 向右
    if (dx == 1 && dy == 0) return 4;  // 向下

    return 0;
}

void collapseLeft(vector<int>& a) {
    for (int row = 0; row < n; row++) {
        vector<int> nums;

        // 从左到右收集非空数字
        for (int col = 0; col < m; col++) {
            int id = getId(row, col);
            if (a[id] != 0) {
                nums.push_back(a[id]);
            }
        }

        // 清空这一行
        for (int col = 0; col < m; col++) {
            a[getId(row, col)] = 0;
        }

        // 从左到右放回
        int col = 0;
        for (int v : nums) {
            a[getId(row, col)] = v;
            col++;
        }
    }
}

void collapseDown(vector<int>& a) {
    for (int col = 0; col < m; col++) {
        vector<int> nums;

        // 从下到上收集非空数字
        for (int row = n - 1; row >= 0; row--) {
            int id = getId(row, col);
            if (a[id] != 0) {
                nums.push_back(a[id]);
            }
        }

        // 清空这一列
        for (int row = 0; row < n; row++) {
            a[getId(row, col)] = 0;
        }

        // 从下到上放回，保持上下相对顺序
        int row = n - 1;
        for (int v : nums) {
            a[getId(row, col)] = v;
            row--;
        }
    }
}

void applyCollapse(vector<int>& a) {
    collapseLeft(a);
    collapseDown(a);
}

ull makeMove(const vector<int>& a, const vector<int>& path) {
    vector<int> b = a;

    int len = path.size();
    int pre = path[len - 2];
    int ed = path[len - 1];

    int newValue = getNewValue(pre, ed);

    // 先清空整条路径
    for (int id : path) {
        b[id] = 0;
    }

    // 在终点生成新数字
    b[ed] = newValue;

    // 先向左坍缩，再向下坍缩
    applyCollapse(b);

    return encode(b);
}

vector<int> getComponentSize(const vector<int>& a) {
    vector<int> compSize(N, 0);
    vector<int> vis(N, 0);

    for (int s = 0; s < N; s++) {
        if (a[s] == 0 || vis[s]) continue;

        vector<int> nodes;
        queue<int> q;

        vis[s] = 1;
        q.push(s);

        while (!q.empty()) {
            int u = q.front();
            q.pop();

            nodes.push_back(u);

            for (int v : adj[u]) {
                if (vis[v]) continue;
                if (a[v] != a[s]) continue;

                vis[v] = 1;
                q.push(v);
            }
        }

        int sz = nodes.size();
        for (int x : nodes) {
            compSize[x] = sz;
        }
    }

    return compSize;
}

int solve(ull state);

void enumeratePaths(
    const vector<int>& a,
    int u,
    int color,
    unsigned int visitedMask,
    vector<int>& path,
    unordered_set<ull>& nextStates,
    int& best
) {
    int len = path.size();

    if (len >= 3) {
        ull nxt = makeMove(a, path);
        nextStates.insert(nxt);
        best = max(best, len);
    }

    for (int v : adj[u]) {
        if (visitedMask & (1u << v)) continue;
        if (a[v] != color) continue;

        path.push_back(v);

        enumeratePaths(
            a,
            v,
            color,
            visitedMask | (1u << v),
            path,
            nextStates,
            best
        );

        path.pop_back();
    }
}

int solve(ull state) {
    if (memo.count(state)) {
        return memo[state];
    }

    vector<int> a = decode(state);

    int best = 0;

    unordered_set<ull> nextStates;
    nextStates.reserve(2048);

    vector<int> compSize = getComponentSize(a);

    for (int s = 0; s < N; s++) {
        if (a[s] == 0) continue;

        // 所在同色连通块大小小于 3，不可能形成合法路径
        if (compSize[s] < 3) continue;

        vector<int> path;
        path.push_back(s);

        enumeratePaths(
            a,
            s,
            a[s],
            1u << s,
            path,
            nextStates,
            best
        );
    }

    for (ull nxt : nextStates) {
        best = max(best, solve(nxt));
    }

    memo[state] = best;
    return best;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    N = n * m;

    pw5[0] = 1;
    for (int i = 1; i <= N; i++) {
        pw5[i] = pw5[i - 1] * 5;
    }

    vector<int> a(N);

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[getId(i, j)];
        }
    }

    adj.assign(N, vector<int>());

    int dx[4] = {-1, 0, 1, 0};
    int dy[4] = {0, 1, 0, -1};

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            int u = getId(i, j);

            for (int d = 0; d < 4; d++) {
                int ni = i + dx[d];
                int nj = j + dy[d];

                if (ni < 0 || ni >= n || nj < 0 || nj >= m) continue;

                int v = getId(ni, nj);
                adj[u].push_back(v);
            }
        }
    }

    ull start = encode(a);

    cout << solve(start) << '\n';

    return 0;
}
```
